# Global Trust Simulator Website

This repository contains the front-end website for the Global Trust Simulator concept build.

## What is included
- Customer sign-in and registration interfaces
- Dashboard layout inspired by a modern financial app
- Mobile-friendly navigation and responsive card layout
- Simulated account activity and transaction history
- Separate admin view with customer search, status controls, and credit simulations
- Demo-only messaging for fictional balances and transactions

## Important note
This project is a front-end website prototype. It does not connect to a live Supabase instance or replace the backend security requirements in the project brief. The UI is built for demonstration and design review, and the Supabase integration layer would need the project URL and keys to be connected in a real deployment.

## Run locally
Open `index.html` directly in a browser or serve the folder with a local static server, for example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
